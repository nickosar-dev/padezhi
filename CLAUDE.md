# Падежи — тренажёр польской грамматики (PWA)

Пользователь читает польские стихи и учит по ним грамматику. Учится только на телефоне (Android, установленное PWA), карточки готовит на этом Mac вместе с Claude. Синк прогресса не нужен: прогресс живёт на телефоне, с компа на телефон едет только колода.

## Устройство
- `index.html` — всё приложение, vanilla JS, без сборки. Прогресс хранится в localStorage `pl-trainer-v2`, скачанная колода в `pl-trainer-content-v1`.
- `sw.js` — офлайн. Файлы приложения отдаёт network-first с кэшем, `packs/` не кэширует.
- `packs/*.txt` — колода, по файлу на стих, в формате импорта Anki: тот же файл можно импортировать в Anki.
- `packs/index.json` генерирует `build_packs.py`, руками не править.
- id заметки = хеш текста первой колонки. Если поправить текст, получится новая карточка с нулевым прогрессом, а старая станет сиротой и пропадёт из показа. Пояснение и теги можно править свободно.
- Иконки рисует `make_icons.py`.

## Как сделать карточки из стиха
1. Файл `packs/<автор>-<стих>.txt` (латиница, через дефис) с заголовком:
   ```
   #separator:tab
   #html:true
   #notetype:Cloze
   #deck:Polish::<Автор>::<Название>
   #tags column:3
   ```
2. Одна строка — одна заметка: `текст<TAB>пояснение<TAB>теги`. Ровно 3 колонки, настоящие табы, поля без кавычек.
3. Текст — строка стиха с пропуском `{{c1::форма::лемма или подсказка}}`, затем `<br><i>русский перевод</i>`. Из HTML разрешены только `<br> <i> <b>`.
4. Одна заметка — один грамматический момент. Пропуски `c1`, `c2`… дают отдельные карточки. Одинаковый номер у нескольких пропусков означает, что их заполняют вместе (согласование: `winą … dużą`).
5. Пояснение: правило в одну-две фразы плюс параллель с русским, если она есть.
6. Теги: автор, строфа (`str1`, `str2`…), падеж каждого пропуска по порядку пропусков (`gen acc dat instr loc voc`), плюс `prep` (предлог), `verb` (глагольная форма), `gov` (карточка-правило об управлении). По падежным тегам приложение красит карточку и считает статистику.
7. Кроме строк стиха полезны карточки-правила («предлог dla требует: {{c1::Dopełniacz}}») и парадигмы глаголов, которые встретились в тексте.
8. **Каждую форму проверить**: падеж, число, род, чередования (kot → kocie). Сомнительное сверить со словарём (sjp.pl, wsjp.pl) или явно пометить пользователю. Лучше меньше карточек, чем одна неверная.
9. `python3 build_packs.py` должен пройти без ошибок, предупреждения нужно прочитать.
10. Опубликовать: `./publish.sh`.
