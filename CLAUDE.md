# Падежи — тренажёр польской грамматики (PWA)

Пользователь читает польские стихи и учит по ним грамматику: все формы, не только падежи (времена, наклонения, вид, предлоги, местоимения, согласование). Учится только на телефоне (Android, установленное PWA), карточки готовит на этом Mac вместе с Claude. Синк прогресса не нужен: прогресс живёт на телефоне, с компа на телефон едет только колода.

## Устройство
- `index.html` — всё приложение, vanilla JS, без сборки. Прогресс хранится в localStorage `pl-trainer-v2`, скачанная колода в `pl-trainer-content-v1`.
- `grammar.html` — справка во вкладке «Грамматика» (HTML-фрагмент). Карточки ссылаются на её якоря через `TOPICS[*].ref` в `index.html`; при добавлении темы добавь и раздел, и якорь.
- `lexicon.json` — словарь для «Грамматика → Тренировка»: приложение само собирает из него задания (строчка с пропуском + русский перевод) по темам из `DRILLS` в `index.html`. Существительные: `sg` = M D C B N Ms W, `pln` = M D C B N Ms, `rsg`/`rpl` — русские И Р Д В Т П; `cls` (person, animal, place, thing) решает, в какие шаблоны слово подходит. Глаголы: `past` = [ja м.р., on, ona, oni], остальные формы прошедшего и условного выводятся; `perf` — пара сов. вида для будущего. Шаблоны: `cases`, `pronCases`, `preps` (`only` — список слов, `q` — где?/куда?). В русских шаблонах `{о:prep}` подставляет предлог с поправкой о/об, с/со. Новое слово или глагол добавлять сюда, все формы проверять так же строго, как карточки. Ошибки тренировки пользователь может отправить в повторения: они становятся «Моими заметками» с тегом `drill` и идут первыми в очереди новых.
- `sw.js` — офлайн. Файлы приложения отдаёт network-first с кэшем, `packs/` не кэширует.
- `packs/*.json` — колода, по файлу на стих. Старый формат `packs/*.txt` (импорт Anki) приложение тоже читает.
- `packs/index.json` генерирует `build_packs.py`, руками не править.
- id заметки = хеш ключа: у пропуска это `text` + `<br><i>tr</i>`, у выбора — `q` + `answer`, у таблицы — `q` + ответы строк. Если поменять что-то из этого, получится новая карточка с нулевым прогрессом. `note`, `topics`, `level`, `tags` можно править свободно.
- Иконки рисует `make_icons.py`.

## Формат пакета
```json
{
  "title": "Автор · Название",
  "source": "Автор, «Название», год",
  "items": [ ... по одной заметке на строку ... ]
}
```
Три типа заметок. Общие поля: `level` (1–3), `tr` (перевод, показывается по нажатию и после ответа), `note` (пояснение после ответа), `topics`, необязательные `tags` (например `str1`). Из HTML разрешены только `<br> <i> <b>`.

- **choice** (уровень 1, узнать форму): `q` — строка стиха с выделенным `<b>словом</b>` и вопрос; `options` — 2–6 вариантов, `answer` — один из них. Варианты перемешиваются. Неверные варианты должны быть однозначно неверными в этом контексте.
- **cloze** (уровень 2, вставить форму): `text` с пропуском `{{c1::форма::лемма, подсказка}}`. Разные номера дают отдельные карточки, одинаковый номер заполняют вместе (согласование). Несколько верных ответов: `{{c1::będą podnosić / będą podnosili::…}}`. Если у пропусков разные темы: `"per": {"2": ["instr","prep"]}`.
- **table** (уровень 3, таблица целиком): `q` и `rows`. Строка `["gen", "tego kraju"]`, где подпись — ключ падежа (`nom gen dat acc instr loc voc`), сама превращается в «Dopełniacz · kogo? czego?», а `loc` получает предлог «o» перед полем. Подпись может быть и текстом (`["ja (м.р.)", "podnosiłem"]`). Третий элемент `1` — строка-подсказка, показывается заполненной (обычно Mianownik).

Темы (`topics`): падежи `nom gen dat acc instr loc voc`, `decl` (склонение целиком), глагол `pres past fut imper cond aspect verb`, другое `prep pron adj mos` (мужско-личная форма). Первая падежная тема задаёт цвет карточки, все темы идут в статистику «Где ошибаешься»; в таблицах падежи считаются по строкам.

## Как сделать упражнения из стиха
1. Файл `packs/<автор>-<стих>.json` (латиница, через дефис).
2. Из каждой строки стиха выписать грамматические моменты: падеж и почему (предлог, глагол, отрицание), формы глаголов (время, лицо, вид), предлоги, согласование.
3. На каждый момент — лестница от лёгкого к сложному:
   - уровень 1: `choice` «в каком падеже / что за форма / какой предлог»;
   - уровень 2: `cloze` прямо в строке стиха, плюс «дробные» упражнения на тех же словах: та же форма в новой короткой фразе, где? / куда?, отрицание, перевод в прошедшее / будущее / повелительное / условное;
   - уровень 3: `table` — склонение слов и сочетаний из стиха (ед. и мн. ч., с прилагательным или ten), спряжение глаголов во встреченных и соседних временах.
4. Пояснение: правило в одну-две фразы плюс параллель с русским, если она есть. Старые или поэтические формы помечать (popsować → сейчас popsuć).
5. **Каждую форму проверить**: падеж, число, род, чередования (kot → kocie, gniazdo → gnieździe), мужско-личную форму. Сомнительное сверить со словарём (sjp.pl, wsjp.pl) или явно пометить пользователю. Лучше меньше карточек, чем одна неверная.
6. `python3 build_packs.py` должен пройти без ошибок, предупреждения нужно прочитать.
7. Опубликовать: `./publish.sh "сообщение"`.
